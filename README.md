## 🌟 Interactive Web Studio & Engineering Manual
This repository hosts the complete interactive web portal and technical engineering manual for **CloudRover V1.0**.

### 🎮 Features:
- **3D Stacking Explorer:** Full breakdown of all 4 mechanical tiers with exploded CAD renders.
- **Fasteners & Hardware Catalog:** High-resolution photographic catalog covering every standoff, screw, nut, diode, and capacitor.
- **Electronics BOM:** Visual board catalog of all 12 modules.
- **3D Printed Parts Studio:** Real-life 3D renders, dimensioned engineering CAD blueprints, and recommended slicer settings for Parts 1, 2, 3, and 4.
- **Interactive Pinout Inspector:** Clickable ESP32 GPIO map with real-time acoustic tone feedback.
- **Cozmo-Style Reactive Mood Simulator:** 11 distinct cute emotional states with independent articulated eyebrows, animated mouth shapes, and Web Audio API synthesizer.
- **Commissioning Protocol:** 8 pre-flight verification gates with interactive progress tracking.
- **Master PDF Manual:** Downloadable 29-page comprehensive build guide included directly in the repo.
